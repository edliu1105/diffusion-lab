统一 λ 轴实验台

所有 diffusion / flow 算法共享一次线性混合 x_t = α·x₀ + σ·ε:信号缩到 α 倍,掺入强度 σ 的噪声。 把 x_t 整体乘一个常数不增减任何信息,所以 (α, σ) 里真正有意义的只有比值——信噪比 SNR = α²/σ²。 λ = logSNR = 2·log(α/σ) 就是它的对数刻度(扩散世界的"分贝"):λ=0 信噪各半,每 +1 信噪比 ×e,+9 近乎干净,−9 近乎纯噪。 各家论文的 t / σ / φ 都只是 λ 的换算标签(卡①);训练在这根轴上分配样本(卡②),预测目标是它上面的坐标选择(卡③), 采样沿它数值积分(卡④),蒸馏把它的区间压成一跳(卡⑤)。

① 时间参数化:每家的 t 都是 λ 的换算

每行是一种论文里的"时间"变量,刻度点 = 该变量的均匀网格映射到 λ 轴上。读法:均匀的是各家自己的 t / σ / φ,从来不是 λ;SD3 的分辨率 shift 在 λ 轴上是整体平移 −2·ln s。右侧数字 = 游标处的换算读数。

② 训练:在 λ 上抽样本 × 给损失定权重

上图:训练时噪声等级的采样密度 p(λ)——各家把梯度花在哪一段。下图:把各家原生损失统一换算成 ‖x̂₀−x₀‖² 后的等效权重 w(λ)(log 刻度,只看形状)。两者相乘才是真实的训练侧重。 2026 的新自由度是λ 的分配粒度:Self-Flow(FLUX 团队,ICML'26)不再整图共用一个 λ,而是给每个 token 独立抽 λ(双时间调度)——干净 token 成为带噪 token 的上下文,信息不对称逼着网络在纯 FM 目标内长出语义表征,取代 REPA 类外部对齐(自报收敛快 ~2.8×)。

③ 预测目标:同一个 E[x₀|x_t] 的五种线性打包

网络唯一学到的对象是后验均值 E[x₀|x_t](经 Tweedie 公式 ↔ score)。ε̂ / x̂₀ / v̂ / û / score 都是它的仿射改写——选择目标 = 选择"一份网络输出误差换多少 x̂₀ 误差"(下图,log 刻度)。ε̂ 在高噪端病态(λ=−8 处 ×55),x̂₀ 与 score 在另一侧病态,v̂ / û / EDM-D 全程有界。选中的目标同时决定探头 A 的向量场与探头 B 的高亮张量。

⑥ 延伸:视频 / 自回归 / 世界模型 —— 多个游标,同一根轴

视频模型的差异可以读成"每一帧此刻站在 λ 轴哪里":整段扩散 = 全部帧绑成一叠齐降;Diffusion Forcing = 每帧独立噪声等级,过去干净、未来更噪;流式因果生成 = 历史帧停在数据端(进 KV cache),当前帧用 1–4 步俯冲。 "逐单元独立 λ"正在成为一根通用设计轴:帧级(Diffusion Forcing,为流式)→ token 级(Self-Flow,为表征,见卡②)。记忆、动作、世界状态不在这根轴上,不在本页范围。
